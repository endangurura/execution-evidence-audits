# Publication policy

This repository is for vetted technical work: methods, schemas, original code,
rights-cleared examples, analyses, and accurately labeled findings.

Before publishing any revision:

- Inspect the exact file list, diff, and history, not only ignore rules.
- Check sources, rights, privacy, sensitive metadata, and dual-use consequences.
- Distinguish proposed methods, implementation tests, experiments, and independent
  validation. Do not make results claims from preparation or synthetic examples.
- Preserve negative results, failed attempts, and reproducibility limitations.
- Obtain the researcher's approval for publication. Creating files locally is not
  permission to publish the repository or broaden document sharing.

No third-party benchmark material is redistributed in the initial contents.
An upstream repository's top-level license does not settle every dependent
paper, dataset, or model license.
