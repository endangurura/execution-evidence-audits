# Research repository instructions

This is a technical publication repository for execution-evidence auditing.
Read README.md and docs/publication_policy.md before edits or publication.

- Preserve the distinction between proposed work, implementation checks, empirical
  findings, independent review, and replication.
- Keep raw and held-out material in separately access-controlled storage.
- Avoid retrieving protected benchmark labels into coding-agent context.
- Prefer existing scientific libraries for measurement and existing evaluation
  tools for execution. A schema is not a correctness scorer or security boundary.
- Keep source citations and limitations next to research claims.
- No experiment, provider spend, commit, or push without the researcher's approval.
